# Evaluating Arithmetic Expressions

## Project Overview

Evaluating Arithmetic Expressions is a software system that evaluates arithmetic expressions using stack-based algorithms.

The project accepts arithmetic expressions in infix notation, converts them into postfix notation, and evaluates the postfix expression using a stack.

The system supports numbers, decimal numbers, variables, arithmetic operators, parentheses, symbolic expressions, and error detection.

---

## Problem Statement

Arithmetic expressions can contain multiple operators and parentheses, making direct evaluation difficult for a computer program.

For example:

```text
10 + 5 * 2
